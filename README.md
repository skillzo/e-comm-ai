# E-Comm AI

Full-stack application with Express backend and Vite frontend using Tailwind CSS 4.

## Setup

### Backend

```bash
cd backend
npm install
npm run dev
```

Server runs on http://localhost:3000

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on http://localhost:5173
